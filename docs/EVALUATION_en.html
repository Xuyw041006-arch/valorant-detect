The annotations have not been independently verified event by event and may contain incorrect labels, omissions or timing errors; their accuracy is not guaranteed.

Method

Precision = TP / (TP + FP); Recall = TP / (TP + FN). Maximum-cardinality one-to-one matching requires the same source clip, event type, team, death/non-death reason, object class or exact state values, within ±0.5 seconds. Duplicates, late observations and misses are counted. Scores cover events and timing, excluding agent or weapon identities, bounding boxes, minimap coordinates and track identities.

Non-death disappearance requires 0.8 seconds of absence. Pure through-wall silhouettes and corpses are excluded from visible bodies. Death requires a new killfeed row. Cuts do not create deaths or disappearances. Numeric HUD events require exact before/after values, including spectator and buy-phase footage.

Interpretation

Track fragmentation generates repeated person events. Several clips miss magazine changes and killfeed events.
